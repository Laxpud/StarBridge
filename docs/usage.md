# 使用StarBridge完成算例任务

适用范围：程序基线`f7eef68`。先按[安装与接入说明](<distribution.md>)连接MCP；本页按任务说明操作，完整字段由[接口文档](<tech/mcp.md>)和按需契约提供。示例只展示格式，不表示已经在读者算例上执行。

## 接手一个已有算例

**准备：**算例在执行机器上的绝对路径，或当前会话标识；知道安装位置时一并提供。路径不是远端聊天客户端的本地路径。

**操作：**已有会话先查询`session_status`并复用。只有文件时，通过`open_session`优先查找匹配的GUI/服务；没有匹配才加载原文件。无保存路径的GUI算例需要明确端口与项目目录。安装选择不明确且会影响目标时，先确定实际安装，不猜版本。

**结果：**得到实际版本、当前加载文件和会话标识。后续相关操作沿用它，不每一步重新打开、关闭。发现未完成、服务忙或身份不匹配不是“没有已有算例”，按返回诊断处理。

## 取得本次需要的接口、资料和经验

默认工具只有`expand_capabilities/query/execute`。不熟悉格式时，向`starbridge.expand_capabilities`提供所需方法，例如：

```json
{"methods":["session_status","search_api","read_api","execute_macro","get_execution"]}
```

按返回的`tool`和`arguments_schema`调用。已有有效格式不必重复展开；不默认取得全部契约、文档或记忆。

- API用`search_api/read_api`按当前安装读取；同一类的多个成员用`members`集中查询，检查每项覆盖。
- 操作前提和指南宏示例用`search_guide/read_guide`；完整代码窗口不一定是独立可执行宏。
- 已有经验先`search_memory`，再按需`get_memory`审阅条件、代码、依据和例外；不照搬旧对象标识、文件路径或参数。

这些查询不运行STAR宏。空结果、正文摘录、分页和读取错误各有含义，不把未找到直接解释为不支持。

## 读取、修改或执行一组明确操作

**准备：**明确当前对象、单位/坐标系、允许的操作与输出范围；优先复用已有可靠代码。普通任务直接使用Java API，不要求先尝试结构化工具。

**操作：**通过`starbridge.execute`调用`execute_macro`，把相关读取、条件判断、修改和回读组织为步骤。现成方法适用时可调用`execute_recipe`，但方法列表不是能力上限。完整宏可原样附带显式辅助源码/JAR；当前纯code没有顶层依赖参数，详见[完整宏用法](<tech/generic-execution.md#原样复用完整宏与辅助源码>)。

**结果：**逐项检查步骤与业务结果，而非只看顶层`ok`。普通步骤须返回需要解释的数据；原样宏成功可能仅表示入口返回，必要时追加明确的业务回读。

常用边界：

| 选项或动作 | 含义 |
| --- | --- |
| 稳定`request_id` | 相同内容返回原凭据，不重复执行；更改内容不能冒用旧标识。 |
| `effect=read` | 声明不修改算例或外部文件；不代表代码沙箱。 |
| `effect=mutate` | 修改、计算、保存或创建诊断CSV/JSON均需此声明；不自动扩大任务授权。 |
| `scope` | 写清当前目标、输出和不改动范围；不是自动覆盖证明。 |
| 自动保存 | 内置网格/求解方法默认拒绝可能触发的已有自动保存；明确允许时才能保留并使用相关设置。 |
| 文件与路径 | 不默认复制算例或资源目录；完整宏的原路径与客户端工作目录是不同概念。 |

## 结果未知、日志较大或连接中断

先经`starbridge.query`读取原请求，不重发可能已经生效的操作：

```json
{"method":"get_execution","arguments":{"session_id":"<current session_id>","request_id":"<original request_id>"}}
```

按返回指引用`read_execution_artifact`读取日志或凭据窗口。日志只有路径不意味着需要重新运行；查询成功也不会自动解除此前未知写入。只有审阅已有依据和当前状态后，才能在支持的范围内使用`reconcile_execution`；它不回滚、不重做，也不认证原任务完成。详见[状态与恢复](<tech/generic-execution.md#完成与恢复>)。

## 在GUI接手、保存或结束工作

需要向用户说明位置时，使用`objects.gui_locations`现成方法取得标准树路径和必要标签；注明观察范围，不冒充另一窗口的选中状态、布局或已刷新缓存。

修改内存、保存当前文件、另存新文件、断开连接是不同动作。按任务明确调用`save_session/close_session`；有修改标志时不能为结束工作擅自保存或`discard`。外部会话的断开不停止用户STAR服务。具体条件见[保存和断开](<tech/bridge-session.md#保存和断开>)。

## 常见使用问题

- **看不到某个业务工具：**当前默认只列三个入口，先按方法名展开，不因工具列表短而认定缺功能。
- **升级后仍是旧行为：**MCP进程不热重载，处理活动请求后重启MCP连接；不因此重新加载算例。
- **图导出少于已存样本：**图表显示/导出选择不必等于全部monitor数据；按任务核对来源、采样和单位，不自动重算或补点。
- **命令和工具成功但无法判断业务结果：**补查已有凭据及必要实际数据，报告未覆盖项；编译、入口返回和物理正确是不同结论。
