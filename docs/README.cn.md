## 适合做什么

StarBridge 目前处于初步规划阶段。仓库中只有设计文档，尚无可运行的插件、CLI 或 MCP 服务。

拟议系统结合结构化算例访问、工作流 Skills、持久化工作记忆，以及后台或 GUI 常驻算例会话。具体定位与边界见[设计文档](../StarBridge.md)。
