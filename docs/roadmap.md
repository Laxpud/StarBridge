## 后续里程碑

版本目录、代表性覆盖与版本演进已提供 MCP 的基础。本轮推进到 MCP，停在 Skills 之前；更多配置覆盖与版本补充继续作为长期任务。各阶段同步直接受影响的文档，GUI 会话接入和持久化工作记忆的实施时点另行确定。

### 目录覆盖扩展与版本演进

目标：通过目录条目、通用类型适配器和必要的特殊操作适配，逐步覆盖算例配置；版本变化主要通过目录差异和映射更新处理。

原 Modifier 未完成项纳入此阶段，保留其读取、检查和回读要求：

- Mesh Controls：已有有向自动源网格 Base Size 通过通用标量入口完成范围、单位、引用和重载验证；继续扩展其他网格控制。
- Boundary Parameters：已有常量标量与向量 Profile 通过父路径、当前方法、局部表面值及写后上下文核对完成代表性验证；继续扩展其他方法与切换关系。
- Selected Physics Settings：已有重力条件、张量及材料系数与方法操作的代表性读写；继续完善模型启停、依赖、其他物性和求解设置。
- Simulation Operations：已有嵌套块可由快照读取，工作流选择已复用通用引用写入并验证保存重载；继续完善块操作、结构关系与相应循环检查。

覆盖继续延伸到几何、其他物理与求解配置、表格、报告、监视器、场景及其他算例内设置。按缺失的属性类型和操作语义补齐适配，避免为每个对象维护独立工具。

同时完成以下版本与覆盖工作：

- 用代表性算例补充目录，保留宏录制、API 材料和实际验证的对应依据；当前算例中未实例化的类型仍可保留在版本目录中。
- 分别统计已发现、可读取、具备写入实现及已实测条目，列出未适配、条件不满足和证据不足的原因；覆盖率说明所用版本、范围及统计基准。
- 已建立 2510 Build 20.06.007 的独立目录，核对调用差异并验证代表性通用读写、拒绝和保存重载；后续继续补充分版本证据，范围见[版本说明](catalog-versions.md)。不能仅凭版本接近就假定兼容。
- 验证属性依赖、方法切换和结构修改；未知或未适配操作应有明确结果，成功回读不代替 CFD 物理合理性判断。

目录基础阶段未完成的扩展与补充验证继续在这里推进：

- 补齐更多模型、方法状态和当前可写条件。已实现声明式只读条件、GravityModel 存在性、张量布局与维数、当前分量方法、材料系数方法，以及已接入边界、网格尺寸与工作流条件；未声明的条件不能由 `writable` 标志推断。
- 扩展其余真实张量、材料与多系数方法、值类型、查询谓词和必要结构操作，保留单位、方向、关联身份、方法切换前后状态及已声明不变属性的核对。
- 验证其余读写分支、目标与模型状态拒绝，按版本记录未覆盖类型和证据缺口，不将静态发现、编译或一次成功回读等同于全部分支验收。
- 随新增通用读写能力同步使用说明、请求与结果契约及迁移边界。

### Skills

逐步积累 STAR-CCM+ 工作流 Skills，例如 `mesh-setup`、`overset-mesh`、`rotor-case`、`oge-case`、`nwse-case`、`vof-setup`、`solver-setup` 和 `case-audit`。

Skills 查询当前版本的目录能力和算例状态，通过统一接口组织工作流，并结合用户、项目及算例记忆理解背景。对象 API 映射和版本差异由目录与执行器维护，避免每个 Skill 重复维护 Java 调用。

Tool 决定 Agent 能做什么，Skill 描述 Agent 如何完成工作。

## Backlog

### 网格与求解执行接口

网格生成与求解仍需独立执行入口，不能合并进配置修改工具。后续明确运行状态、停止与取消、失败恢复及实际结果核验，再通过共享 Core 接入 MCP；当前没有对外执行工具。

### Inspector 读取深度与补充验证

当前字段契约、已验收分支与限制见 [Inspector 对象快照](inspector.md)。尚未覆盖的参数类型、字段与错误场景，以及其他设置的读取纳入[目录覆盖扩展与版本演进](#目录覆盖扩展与版本演进)；现有对象清单不等于完整设置导出。

### 常驻 Java 适配器与 GUI 接入

价值：在后台服务常驻的基础上，进一步消除每次启动 Java 客户端的开销；允许用户和 Agent 操作同一个 GUI 会话。
待明确：常驻请求接收、API 调用线程、异常恢复，以及共享状态协调。目录可以描述操作条件，但不能替代实际并发协调。当前只实施短生命周期客户端方案，此项后续再研究。

### 持久化工作记忆

价值：跨对话保留用户偏好、项目约定和算例背景。
待明确：用户、项目、算例身份关联，记忆检索、纠正与失效规则；不作为当前目录与读写基础的前置条件。
