### 当前里程碑：MCP 与共享 Core API

目标：将已验证的代表性目录能力和两个明确版本，通过少量稳定的本机 MCP 工具与资源提供给 Agent；CLI 与 MCP 使用相同业务逻辑，在 Skills 之前停止。

说明：[MCP 与共享 Core API](../mcp.md)。目录基础与代表性扩展已归档，更多算例配置仍在[路线图](../roadmap.md#目录覆盖扩展与版本演进)。

完成条件：官方 MCP 客户端能够发现工具与资源，查询两个版本的目录能力，操作明确会话中的对象，完成代表性读写、拒绝、另存与独立重载。错误保留明确拒绝和结果不确定的区别；会话生命周期、原文件保护与旧入口保持可用。

- [x] 提供共享 Service 与 JSON CLI，复用现有目录、Inspector、Modifier、版本检查和后台会话执行器。
- [x] 增加目录对象查找，返回完整父路径、会话身份、名称歧义标记及明确分页状态。
- [x] 提供能力查询、查找、描述、读取、统一修改、快照与会话生命周期 MCP 工具。
- [x] 提供接口契约与版本目录能力资源，使用官方 SDK 的 stdio 传输。
- [x] 校验原始工具参数，统一结构化状态封套与 isError，保留逐属性错误和 uncertain 恢复约定。
- [x] 用官方客户端验证两个版本的代表性调用；核对旧值与引用拒绝、客户端断开后重连、另存重载、超时状态及显式清理。
- [x] 核对共享 JSON CLI、原文件入口及 MCP 的结果一致性和原输入保护。
- [x] 同步安装、请求、结果、验证范围与未实现能力说明。
