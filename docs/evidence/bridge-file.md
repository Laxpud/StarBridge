## 已确认的范围

2026-10-20 的原型验证环境为本机 Linux、STAR-CCM+ 2602 Build 21.02.007，以及用户提供的 `Base.sim~`。首次在 `C.UTF-8` 环境启动时遇到 STAR 数值格式提供器递归错误，随后对子进程使用 `en_US.UTF-8`；其他主机是否需要这一设置未验证。

早期参数原型的实际输入共读取到 32 个标量全局参数，无参数读取错误。将 `_AirfoilPitchAmplitude` 从 `5 deg` 改为 `6 deg` 后，新文件重新加载结果与保存后快照一致；参数 Diff 只有该项，输入文件摘要保持一致。

迁入共享目录后的 `modify` / `set-scalar` 已完成旧字段兼容、完整快照与目录重载核对，具体验收与限制见 [Modifier](modifier.md#已确认的范围)。

上述早期参数原型没有执行网格生成或求解，也未验证向量、其他参数类型、异常单位、MCP 或工作记忆功能。扩展对象读取的验证范围见 [Inspector](inspector.md#验证范围)。后台会话的验证范围单独记录在[会话说明](../tech/bridge-session.md#验证边界)。
