# 三端插件、会话接入与运行简化计划

状态：实施中。前两部分及第三部分的执行层改造已完成；三端插件本地交付和安装验证已完成，Git 推送与远端 DSH 安装验证进行中；统一对外接口和旧入口迁移尚未完成。真实 GUI 接入、保存、失败恢复和收窄后的写入链路尚未实测，当前边界见[会话说明](../bridge-session.md)。

依据：[规格](../specs/spec-2026-11-03-14-23.md) · [ADR 0002](../adr/0002-plugins-sessions-and-storage.md)

## 实施顺序

### 1. 调整会话与文件位置

- [x] 优先连接匹配的已有 STAR GUI／服务器，没有可用会话时启动后台服务并直接加载原算例。
- [x] 区分外部会话和自有会话，分别处理断开连接与停止进程。
- [x] 移除强制算例副本和源文件 SHA256 检查，不自动生成备份副本。
- [x] 实现保存当前算例与另存为的语义，保持保存由明确指令触发。
- [x] 按规格管理项目位置、项目 `.starbridge` 产物和用户 `~/.starbridge` 运行数据，隐藏内部会话路径的管理细节。
- [x] 精简常规运行产物，按调试需要保留详细文件，并采用简单的日志与缓存保留规则。

### 2. 简化状态与读写检查

- [x] 区分请求失败、仍在执行和写入结果未确认，取消只读失败导致的会话冻结，允许通过状态查询和读取核对未确认写入。
- [x] 将普通赋值的检查限制在目标、旧值、回读及必要关联项，取消强制的旧 Inspector 全范围不变检查。
- [x] 将完整快照和 Diff 保留为按需审查功能。
- [x] 使用会话内短 ID 替换对象和分页引用的 HMAC 签名，删除专用密钥及管理逻辑。

### 3. 收敛读取与执行链路

- [x] 改为直接传递内部计划，去除写入 JSON 后再加载及重复检查。
- [x] 复用安装版本相关的类型适配和缓存，取消每次读取的 Javadoc 内容摘要检查。
- [x] 去除读取和分页中的无关写入计划及重复描述准备。
- [x] 从复用执行资源、合并请求入手，减少重复宏生成与客户端启动，不预设常驻 RPC 架构。
- [ ] 统一对外对象、属性和读写表达；迁移现有能力后移除旧接口及结果投影。
- [x] 精简 MCP 返回内容，去除同一数据的重复包装。

### 4. 交付三端插件

- [x] 为 Codex、Claude Code 和 DSH 提供轻量插件适配，共用程序与 Skill 内容。
- [x] 通过插件初始化必要运行环境，使程序和 Skill 使用同一发布版本。
- [x] 使用三端原生安装与更新入口，取消用户分别安装程序、MCP 配置和 Skill 的流程，不另建升级器。
- [x] 保留源码与通用 CLI／MCP 接入说明，停止维护其他 Harness 的专用适配。
